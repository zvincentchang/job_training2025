第五章.React Component 父子組件"溝通"

● 父子組件溝通
1.父子組件"溝通"方式一
父傳子:子元件透過 "props" 呼叫父組件函式
子傳父:父元件透過 "ref" 呼叫子組件函式
<Child ref={this.childRef} addParentCount={this.addParentCount}/> 
程式範例：Component_Parent_Child_Deliver/Parent.js、Child.js、index.js

2.父子組件"溝通"方式二
完全由父組件來主導全部的 state 儲存至 props 操作子組件
子組件再透過 props 解構"取值"、"取函數"
程式範例：Component_Parent_Child_Deliver/ParentTwo.js、ChildTwo.js、index.js


● 樣式控制: className 與 style
1.三元運算子、判斷式
2.控制 style JSX 物件
3.控制 className
程式範例：Component_Parent_Child_Deliver/CtrlStyle.js、index.js


● 組件有三種
1.class Component
2.PureComponent
    2.1
    PureComponent與Component差異在效能上，當上層元件所傳入下層元件的props中的值若"未改變"的話
    PureComponent是不會重新render，但Component與Functional Component 都會重新render效能較差
    2.2
    PureComponent 也會比較自已的state
    shallow compare 淺層比較 (只比較state的第一層)
    只有第一層值有更新時才會render
3.Functional Component (Statless無狀態)

程式範例：Component_Parent_Child_Deliver/ProgressPercent、Progress.js、index.js

備註說明:
(1)在componentDidMount 透過 set­State(Updating) 會再次觸發 render(渲染函式)使畫面重新繪製
(2)componentDidUpdate 透過 prevState 與前次的state中的值相比,判斷是否要更新組件set­State(Updating)

第九章.React Hooks

React Hooks (16.8版)於2019/2/6之後引入
https://reactjs.org/docs/hooks-intro.html
1.使用函式組件(functional component)的方式來建構,而不用class component類別組件
2.React團隊當初在設計Hooks的用意就在，使用函式組件(functional component)的時候
也能夠自由的使用這個state，也能夠做到這個生命週期函式可以做到的事情
3.使用Hooks可以把相同的邏輯組織起來放在同一個地方

● Hooks useState(狀態管理)
使用函式組件(functional component) 不能直接使用 state 必須透過 Hooks useState(狀態管理)
使用 Hooks 就可以使用函式組件(functional component)來操作 state
import React, { useState } from 'react';
程式範例：Hooks/UseStateApp.js、UseStateApp2.js

● Hooks useEffect(附加效果)
相當於 componentDidMount、componentDidUpdate、componentWillUnmount
程式範例：Hooks/UseEffectApp.js、UseEffectApp2.js

● Hooks useContext(應用Context)
1.Function Component 父傳子
程式範例：HooksUseContext/Before/UseFunOpenButton.js、UseFunOpenButtonDiv.js、UseFunOpen.js
2.使用 useContext 取代 Context API Consumer
程式範例：HooksUseContext/context.js、UseContextOpenButton.js、UseContextOpenButtonDiv.js、UseContextOpen.js

● Hooks useRef(存取參照)
使用 useRef 取代 createRef
1.ref 儲存DOM的參照
程式範例：HooksUseRef/UseRefDom.js
2.ref 儲存instance function實例函式
程式範例：HooksUseRef/UseRefFunctions.js
3.Function Component 子傳父
程式範例：HooksUseRef/UseRefChild.js、UseRefParent.js

● Hooks 綜合應用 TodoList(useState + useEffect + useContext + useRef)
程式範例：HooksTodoList/context.js、TodoInput.js、TodoList.js
