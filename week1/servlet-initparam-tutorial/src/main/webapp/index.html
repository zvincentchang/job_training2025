🎯 教學目標

本教學專案將示範如何在 Java Servlet 中使用初始化參數 (InitParam)。 您將學習到兩種不同的配置方法：傳統的 web.xml 配置方式和現代的 @WebServlet 註解方式。 透過實際的程式碼範例，您可以理解兩種方法的優缺點和適用場景。

📞 您要求的程式碼範例輸出

// 在 Servlet 中讀取 InitParam String name = super.getInitParameter("username"); response.setContentType("text/html;charset=utf-8"); response.getWriter().append("<h2>UserName is ").append(name+"</h2>");
UserName is 張小明
🔧
web.xml 配置方式
傳統的 XML 配置方式，在 web.xml 文件中定義 Servlet 和其初始化參數。 這種方式提供了靈活的外部配置能力。
查看 web.xml 範例
📝
@WebServlet 註解方式
現代的註解配置方式，直接在 Java 類別上使用 @WebServlet 和 @WebInitParam 註解。 程式碼更簡潔，配置與實作緊密結合。
查看註解範例
📊 兩種方法詳細比較
比較項目 web.xml 配置 @WebServlet 註解
配置方式 外部 XML 文件 Java 註解
Servlet 版本 所有版本支援 Servlet 3.0+
配置靈活性 高 - 無需重新編譯 低 - 需要重新編譯
程式碼簡潔性 分離配置，需維護兩處 配置與實作在一起
執行時修改 支援（重啟容器） 不支援
團隊協作 配置集中管理 分散在各 Java 檔案
學習門檻 需了解 XML 語法 Java 開發者友善
最佳適用場景 企業級應用、需要靈活配置 快速開發、小型應用
💡 核心程式碼比較

🔧 web.xml 配置方式

<!-- web.xml 文件中 --> <servlet> <servlet-name>WebXmlInitParamServlet</servlet-name> <servlet-class>com.example.servlet.WebXmlInitParamServlet</servlet-class> <init-param> <param-name>username</param-name> <param-value>張小明</param-value> </init-param> </servlet> // Java 類別中 public class WebXmlInitParamServlet extends HttpServlet { String name = super.getInitParameter("username"); }

📝 @WebServlet 註解方式

// Java 類別中直接註解配置 @WebServlet( name = "AnnotationInitParamServlet", urlPatterns = {"/AnnotationInitParamServlet"}, initParams = { @WebInitParam(name = "username", value = "John Doe"), @WebInitParam(name = "email", value = "john.doe@example.com") } ) public class AnnotationInitParamServlet extends HttpServlet { String name = super.getInitParameter("username"); }
